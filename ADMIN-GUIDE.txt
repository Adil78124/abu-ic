# 📖 Руководство по использованию админ-панели

## 🔐 Как войти в админку

1. Откройте браузер (Chrome, Edge, Firefox и т.д.)
2. Введите в адресной строке: `http://localhost:8080/admin-login.html`
3. Введите логин: `abu_ic_control`
4. Введите пароль (тот, который вы установили в Supabase)
5. Нажмите кнопку **"Войти"**

---

## 🏠 Главная страница админки

После входа вы увидите главную страницу с ссылками на все админки.

**Навигация между админками:**
В верхней части каждой админки есть навигационное меню с иконками, которое позволяет быстро переключаться между разными админками:
- 📰 **Админка новостей** - обычные новости сайта
- 🏠 **Новости главной страницы** - новости для главной страницы и страницы международного сотрудничества
- 📞 **Данные футера** - контактная информация в футере
- 🎛️ **Unified Admin** - все остальные сущности (партнеры, документы и т.д.)

---

## 📋 Список всех админок

После входа вы увидите четыре ссылки:

### 1. **Админка новостей** (`admin.html`)
   - Используется для управления новостями
   - Здесь можно добавлять, редактировать и удалять новости
   - Загружать изображения для новостей

### 2. **Новости главной страницы** (`admin-main-news.html`)
   - Управление новостями, которые отображаются на главной странице и странице международного сотрудничества
   - Можно добавлять, редактировать, удалять новости
   - Загружать изображения для новостей
   - Управлять порядком отображения новостей

### 3. **Данные футера** (`admin-footer.html`)
   - Управление контактной информацией в футере сайта
   - Адрес, телефон, email, расписание работы
   - Поддержка трех языков (RU, EN, KZ)

### 4. **Unified Admin** (`admin-unified.html`)
   - Используется для управления всеми остальными сущностями сайта
   - Партнеры, документы для студентов, преподавателей и т.д.

---

## 📰 Админка новостей (`admin.html`)

### Как добавить новость:

1. Нажмите кнопку **"Добавить новость"**
2. Заполните поля:
   - **Заголовок (RU)** - обязательное поле
   - **Заголовок (KZ)** - опционально
   - **Заголовок (EN)** - опционально
   - **Содержание** - текст новости
   - **Изображение** - можно загрузить файл или вставить URL
3. Нажмите **"Сохранить"**

### Как редактировать новость:

1. Найдите нужную новость в списке
2. Нажмите кнопку **"Редактировать"** (иконка карандаша)
3. Измените нужные поля
4. Нажмите **"Сохранить"**

### Как удалить новость:

1. Найдите нужную новость в списке
2. Нажмите кнопку **"Удалить"** (иконка корзины)
3. Подтвердите удаление

---

## 🏠 Новости главной страницы (`admin-main-news.html`)

Эта админка управляет новостями, которые отображаются на главной странице сайта и на странице международного сотрудничества.

### Как добавить новость:

1. Нажмите кнопку **"Добавить новость"**
2. Заполните поля:
   - **Заголовок (RU)** - обязательное поле
   - **Заголовок (EN)** - опционально
   - **Заголовок (KZ)** - опционально
   - **Описание (RU)** - краткое описание новости
   - **Описание (EN)** - опционально
   - **Описание (KZ)** - опционально
   - **Ссылка** - URL для перехода при клике на новость (опционально)
   - **Изображение** - можно загрузить файл или вставить URL
   - **Порядок отображения** - число для сортировки (меньше = выше в списке)
   - **Активна** - отметьте, чтобы новость была видна на сайте
3. Нажмите **"Сохранить"**

### Как редактировать новость:

1. Найдите нужную новость в списке (отображаются в виде карточек)
2. Нажмите кнопку **"Редактировать"** (иконка карандаша)
3. Измените нужные поля
4. Если нужно заменить изображение:
   - Выберите новый файл (старое изображение останется в Cloudflare, но будет заменено новым)
   - Или вставьте новый URL вручную
5. Нажмите **"Сохранить"**

### Как удалить новость:

1. Найдите нужную новость в списке
2. Нажмите кнопку **"Удалить"** (иконка корзины)
3. Подтвердите удаление

**Важно:** 
- Новости отображаются в слайдере на главной странице
- Изменения применяются сразу после сохранения
- Для просмотра изменений обновите страницу сайта (Ctrl+F5)

### Особенности:

- **Порядок отображения**: Новости сортируются по полю "Порядок отображения" (по возрастанию), затем по дате создания
- **Многоязычность**: Поддерживается три языка - русский, английский, казахский
- **Изображения**: Загружаются в Cloudflare R2, автоматически создается публичный URL
- **Статус**: Можно временно скрыть новость, сняв галочку "Активна"

## 📞 Данные футера (`admin-footer.html`)

Эта админка управляет контактной информацией, которая отображается в футере на всех страницах сайта.

### Что можно редактировать:

1. **Адрес** - физический адрес офиса (на трех языках: RU, EN, KZ)
2. **Телефон** - контактный телефон
3. **Email** - электронная почта
4. **Рабочие часы** - время работы офиса (на трех языках)
5. **Обеденный перерыв** - время обеденного перерыва (на трех языках)

### Как редактировать данные футера:

1. Откройте страницу **"Данные футера"** (`admin-footer.html`)
2. Данные автоматически загружаются из базы
3. Переключитесь между языками (RU, EN, KZ) для редактирования текстов
4. Измените нужные поля:
   - **Адрес (RU/EN/KZ)** - адрес офиса на разных языках
   - **Телефон** - контактный телефон (один для всех языков)
   - **Email** - электронная почта (один для всех языков)
   - **Рабочие часы (RU/EN/KZ)** - время работы на разных языках
   - **Обеденный перерыв (RU/EN/KZ)** - время обеденного перерыва на разных языках
5. Нажмите **"Сохранить"**

### Особенности:

- **Автоматическое применение**: Изменения применяются на всех страницах сайта автоматически
- **Многоязычность**: Каждый текст можно указать на трех языках
- **Единая запись**: В базе хранится одна запись с последними данными
- **Fallback**: Если текст не указан на текущем языке, используется русская версия

### Пример заполнения:

**Адрес (RU):** `Ильяшева 94, 101 каб, Семей, 071400`
**Адрес (EN):** `Ilyasheva 94, office 101, Semey, 071400`
**Адрес (KZ):** `Ильяшева 94, 101 каб, Семей, 071400`

**Телефон:** `+7 (7222) 42-32-24`

**Email:** `internationaloffice@abu.edu.kz`

**Рабочие часы (RU):** `понедельник – пятница, 9:00 – 18:00`
**Рабочие часы (EN):** `Monday – Friday, 9:00 AM – 6:00 PM`
**Рабочие часы (KZ):** `дүйсенбі – жұма, 9:00 – 18:00`

**Обеденный перерыв (RU):** `обеденный перерыв: 13:00 – 14:00`
**Обеденный перерыв (EN):** `lunch break: 1:00 PM – 2:00 PM`
**Обеденный перерыв (KZ):** `түскі үзіліс: 13:00 – 14:00`

## 🎛️ Unified Admin (`admin-unified.html`)

Эта админка управляет всеми остальными сущностями сайта.

### Типы сущностей:

1. **Наши партнеры** (`our_partners`)
   - Университеты-партнеры
   - Обязательные поля: Название университета (RU), Страна (RU), PDF файл

2. **Студенты** (`students_appendices`)
   - Документы для студентов
   - Обязательные поля: Название (RU), PDF файл

3. **Преподаватели** (`teachers_documents`)
   - Документы для преподавателей
   - Обязательные поля: Секция, Название (RU), PDF файл

4. **MSchool** (`mschool_documents`)
   - Документы для международной школы бизнеса
   - Обязательные поля: Секция, Название (RU), PDF файл

5. **Брошюры** (`brochure_documents`)
   - Брошюры и информационные материалы
   - Обязательные поля: Название (RU), PDF файл

6. **Академическая мобильность** (`eramus_documents`)
   - Документы по программе Erasmus
   - Обязательные поля: Название (RU), PDF файл

7. **Иностранным студентам** (`for_foreign_students_documents`)
   - Документы для иностранных студентов
   - Обязательные поля: Название (RU), PDF файл

## ➕ Как добавить новую сущность

1. Нажмите кнопку **"Добавить"** (в правом верхнем углу)
2. Выберите **"Тип сущности"** из выпадающего списка
3. Заполните обязательные поля (помечены звездочкой *)
4. Загрузите файлы (PDF, изображения) или вставьте URL
5. Нажмите **"Сохранить"**

### Загрузка файлов:

#### Вариант 1: Загрузка с компьютера
1. Нажмите на область **"Выберите файл"** (пунктирная рамка)
2. Выберите файл на вашем компьютере
3. Файл автоматически загрузится в Cloudflare R2
4. После загрузки появится зеленый индикатор "✓ Загружено успешно!"
5. URL файла автоматически заполнится в поле ниже

#### Вариант 2: Вставка URL
1. Если файл уже загружен в интернет
2. Скопируйте URL файла
3. Вставьте его в поле **"Или введите URL"**

### Важно:
- **PDF файлы** обязательны для большинства типов сущностей
- **Изображения** (флаги, карточки) опциональны
- После выбора файла превью появится сразу (желтый индикатор "Готов к загрузке")
- После нажатия "Сохранить" файл загрузится и появится зеленый индикатор

1. Найдите нужную сущность в списке

3. Подтвердите удаление

## 🔍 Фильтры и поиск

В Unified Admin есть несколько фильтров:

1. **Тип сущности** - выберите конкретный тип (например, "Наши партнеры")
2. **Статус** - "Активна" / "Неактивна" / "Все"
3. **Поиск** - введите текст для поиска по названиям и описаниям
4. **Страна** (только для партнеров) - выберите страну из списка
5. **PDF файл** - "Есть PDF" / "Нет PDF" / "Все"

### Как использовать фильтры:

1. Выберите нужные фильтры
2. Список автоматически обновится
3. Чтобы сбросить фильтры, выберите "Все" или очистите поля

---

## ✅ Чекбокс "Активна"

- **Отмечен** - сущность видна на сайте
- **Не отмечен** - сущность скрыта с сайта (но остается в базе данных)

Используйте это для временного скрытия сущностей без удаления.

## ⚠️ Частые ошибки и их решение

### Ошибка: "Поле обязательно для заполнения"
**Решение:** Заполните все поля, помеченные звездочкой (*)

### Ошибка: "Необходимо загрузить PDF файл"
**Решение:** 
- Либо загрузите PDF файл с компьютера
- Либо вставьте URL существующего PDF файла

### Ошибка: "413 Request Entity Too Large"
**Решение:** Файл слишком большой. Уменьшите размер файла (максимум 100MB)

### Файл не загружается
**Решение:**
1. Проверьте размер файла
2. Проверьте формат файла (PDF для документов, PNG/JPG/WEBP для изображений)
3. Попробуйте загрузить файл позже
4. Если не помогает, используйте вариант с URL

### Изменения не отображаются на сайте
**Решение:**
1. Проверьте, что чекбокс "Активна" отмечен (для новостей и сущностей)
2. Обновите страницу сайта (Ctrl+F5 для полной перезагрузки)
3. Очистите кэш браузера
4. Для данных футера: изменения применяются автоматически на всех страницах после сохранения

### Новости главной страницы не отображаются
**Решение:**
1. Проверьте, что новость отмечена как "Активна"
2. Проверьте поле "Порядок отображения" (меньшие числа отображаются первыми)
3. Убедитесь, что загружено изображение
4. Обновите страницу сайта (Ctrl+F5)

### Данные футера не обновляются
**Решение:**
1. Убедитесь, что вы нажали кнопку "Сохранить" в админке
2. Проверьте, что скрипт `footer-loader.js` подключен на странице
3. Обновите страницу сайта (Ctrl+F5)
4. Проверьте консоль браузера (F12) на наличие ошибок
